# Course Overview

Welcome to Higher Level Physics! This course covers the essential topics from the Leaving Certificate Physics syllabus.

## What You'll Learn

This course is organised into key areas:

- **Mechanics** - Motion, forces, work, energy and power
- **Heat & Temperature** - Thermal physics and thermodynamics
- **Waves** - Sound, light, and wave phenomena
- **Electricity** - Circuits, current, and electrostatics
- **Magnetism** - Magnetic fields and electromagnetic induction
- **Modern Physics** - Atomic, nuclear, and particle physics

## How to Use This Course

Navigate through the sections using the sidebar or the Course Navigator button in the top right. Each topic includes:

- Theoretical explanations
- Worked examples
- Interactive exercises
- Practice questions

## Getting Started

Start with the Knowledge Graph to see how topics connect, then dive into the content that interests you most.

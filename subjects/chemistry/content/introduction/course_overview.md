# Course Overview

Welcome to Higher Level Chemistry! This course covers the essential topics from the Leaving Certificate Chemistry syllabus.

## What You'll Learn

This course is organised into key areas:

- **Atomic Structure & Periodic Table** - Understanding elements and their properties
- **Chemical Bonding** - How atoms combine to form compounds
- **Stoichiometry** - Quantitative relationships in chemistry
- **Organic Chemistry** - Carbon-based compounds and reactions
- **Rates of Reaction & Equilibrium** - Kinetics and thermodynamics
- **Acids, Bases & pH** - Acid-base chemistry
- **Electrochemistry** - Redox reactions and electrolysis

## How to Use This Course

Navigate through the sections using the sidebar or the Course Navigator button in the top right. Each topic includes:

- Theoretical explanations
- Worked examples
- Interactive exercises
- Practice questions

## Getting Started

Start with the Knowledge Graph to see how topics connect, then dive into the content that interests you most.
